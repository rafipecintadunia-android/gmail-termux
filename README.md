# gmail-termux
Gmail API sederhana via Termux - Pamekasan

Project buat kirim/baca Gmail dari HP Android pakai Python.

## Cara pakai
1. `pip install google-api-python-client google-auth-oauthlib`
2. Aktifkan Gmail API di Google Cloud Console
3. Download `credentials.json` taruh di folder ini
4. `python gmail_simple.py`
